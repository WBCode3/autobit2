# autobit2

Freqtrade 기반 **Binance USDT-M 선물** 전략 연구 저장소입니다.

> ⚠️ 연구/백테스트 목적이며 투자 조언이 아닙니다. 고레버리지 선물은 전 재산을 잃을 수 있습니다. 아래 수치는 과거 데이터 백테스트 결과이며 실전 수익을 보장하지 않습니다.

## 저장소 구성

| 경로 | 내용 |
| :--- | :--- |
| `strategies/` | 전략 4개 + 동적 유니버스 헬퍼 (`dyn_univ_helper.py`, `G4_M2_B25_m44`이 사용) |
| `configs/backtest_top10.example.json` | 백테스트용 예제 설정 (비밀값은 전부 `CHANGE_ME`) |
| `scripts/` | 슬리피지(POV) 재현 / 구간 백테스트 스크립트 (경로는 본인 환경에 맞게 수정) |
| `HANDOFF.md` | 진행 상황, 검증된 실패 방향 |
| `BOT_USAGE.md`, `docker-compose.yml` | 운용 가이드 / 실행 예시 |

## 공통 구조 (4h 전략: R9, R8, G4)

- **진입**: 변동성 확장(`ATR 비율 > 1.08`로 처음 돌파) + 8봉 돈치안 채널 돌파 + 거래량 `> 20봉 평균 × 1.1` + 펀딩비 필터.
- **방향 필터**: BTC 일봉 `EMA50` 위면 롱만, 아래면 숏만 (전일 값 사용). 즉, 하락 추세에서는 숏을 잡고 롱은 잡지 않습니다.
- **체결**: 시장가가 아니라 `현재가 75% + 돈치안 25%` 지점 지정가를 시도합니다.
- **청산**: 종가가 `EMA20`을 되돌려 넘으면 청산. 보조로 `minimal_roi`(`+80%`/24h 뒤 `+42%`/48h 뒤 `+20%`)와 고정 손절.
- **레버리지**: `ADX >= 32` → `8x`, `>= 22` → `7x`, 그 외 `5x`.
- **보호장치**: 손절 직후 쿨다운(1봉), 12봉 안에 손절이 나오면 4봉 신규 진입 중지(`StoplossGuard`).
- **포지션 크기**: 연패 수에 따라 줄이는 구조(아래 표 참고).

## 모델 설명

### 1. `R9_Dyn90_SL18_StrHi_MR2` — 공격적 메인 (4h)

- 위 공통 구조 + **평균회귀(`mr`) 보조 진입**: `z-score(6봉) ±2.1~2.2`, `RSI < 28 / > 74`, 볼린저밴드 이탈 + 거래량 `×1.6` + 반대 방향 캔들. **다른 포지션이 열려 있으면 진입하지 않습니다(유휴일 때만).** `mr` 청산은 `+16%` / `-12%` / `32시간` 경과.
- **동적 슬롯(`DynSlot`)**: 열린 포지션 수에 따라 기본 배수가 달라집니다. `brk`는 `0개 7.2 → 1개 4.4 → 2개 2.6 → 3개+ 1.6`, `mr`은 `4.0`.
- **연패 감쇠**: 최근 연속 손실 `1회 ×0.62`, `2회 ×0.30`, `3회+ ×0.22`.
- 손절 `-18%`. `TOP10` 고정 유니버스 기준으로 튜닝.
- **성향**: 수익이 가장 높지만 낙폭이 큽니다.

### 2. `R8_Dyn85_SL18` — 단순형 (4h)

- `R9`에서 `mr`을 뺀 **순수 돌파(`brk`) 전략**. 기본 배수 `6.8 → 4.4 → 2.6 → 1.6`, 연패 감쇠 `0.55 / 0.30 / 0.18`.
- 청산은 `populate_exit_trend`의 `EMA20` 되돌림. 손절 `-18%`.
- **성향**: 구조가 단순하고 `R9`보다 낙폭이 약간 낮습니다.

### 3. `G4_M2_B25_m44` — 인과적 동적 유니버스 (4h)

- 돌파 로직은 같지만 **미래 정보 없이 그 시점의 거래량 순위로 유니버스를 고르는** `get_univ_hybrid(whitelist, 6, 12, 4, 180)` 필터를 씁니다 (`TOP10` 생존자 편향을 줄이려는 목적). 고정 슬롯 배수 `4.4`, 손절 `-22%`.
- 39개 페어 화이트리스트 기준으로 검증했습니다. 수익은 `R9/R8`보다 훨씬 낮습니다.

### 4. `P3_1h_Breakout_LowCorr` — 보완용 (1h)

- `1h` 봉, `ATR 비율 > 1.15` 변동성 돌파 + 24봉 돈치안 + 거래량 `×1.5` + `ADX > 20` + BTC 일봉 `EMA50` 방향 필터.
- 레버리지 `4x`, 배수 `2.0`, 손절 `-12%`, `EMA24` 되돌림 청산.
- **성향**: 수익은 낮지만 `4h` 전략이 부진한 횡보 구간에서 방어력이 있습니다. 같은 계좌에서 `4h`와 합치면 `4h` 거래가 줄어 오히려 나빠졌고(`HANDOFF.md`), 별도 계좌로 분리하는 용도입니다.

## 알아둘 한계

1. **낙폭이 큽니다.** `R9/R8`은 5Y 최대 낙폭이 `55~75%`입니다. 실전 운용은 레버리지·배수를 낮춘 버전이 필요합니다 (아직 튜닝 전).
2. **`TOP10` 생존자 편향**: 지금의 상위 10개 코인으로 과거를 돌렸습니다.
3. **과최적화 위험**: 같은 5년 데이터로 파라미터를 골랐습니다. 앞으로 같은 성과가 나온다는 보장이 없습니다.
4. 승률이 `~38%`로 낮고 연패 구간이 깁니다. 규칙대로 버틸 수 있어야 의미가 있습니다.
5. **하락 추세에서는 롱이 막혀 있습니다** (BTC 일봉 `EMA50` 아래). 반대로 반등 초입에는 진입이 늦습니다.

## 실행 방법 (백테스트)

```bash
# 데이터 다운로드 (BTC 일봉과 펀딩비 데이터가 전략에서 필요합니다)
freqtrade download-data --config configs/backtest_top10.example.json \
  --trading-mode futures --timeframes 4h 5m 1h 1d --timerange 20211113-

# 백테스트 예시
freqtrade backtesting --config configs/backtest_top10.example.json \
  --strategy R9_Dyn90_SL18_StrHi_MR2 --strategy-path strategies \
  --timerange 20231114-20261114 --timeframe-detail 5m --fee 0.00035
```

> 전략 코드가 `user_data/data/binance/futures/` 아래의 BTC 일봉과 페어별 펀딩비 파일을 직접 읽으므로, 실행 폴더에 `user_data/data`가 있어야 합니다.
